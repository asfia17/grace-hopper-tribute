# Grace Hopper — Tribute Page

A responsive tribute webpage dedicated to **Grace Hopper**, a pioneer in computer science and programming.

This project was built as part of my web development learning journey while practicing semantic HTML, responsive CSS, layout design, and accessibility-friendly structure.

## ✨ Features

- Responsive design for desktop and mobile
- Semantic HTML structure
- Grace Hopper timeline
- Contributions to computing and programming
- Responsive image
- Quote section
- External biography link
- Mobile-friendly layout

## 🛠️ Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Responsive Design
- Media Queries

## 📚 What I Practiced

Through this project, I practiced:

- Structuring webpages using semantic HTML
- Creating responsive layouts
- Working with images and external links
- Building timeline-style content
- Using CSS Grid and Flexbox
- Designing responsive interfaces with media queries

## 🎯 FreeCodeCamp Project

This project was created for the **Responsive Web Design** curriculum on FreeCodeCamp.

The page fulfills the required user stories and passes the FreeCodeCamp Tribute Page tests.
